# React Real Estate Web Platform (MVP)

## overview
This project is a frontend-only Real Estate Web Platform built using **React + Vite** as part of a machine test assignment.  
It demonstrates property listings, role-based dashboards, protected routes, and mocked interactions.

---

## 🛠 Tech Stack
- React JS (Functional Components)
- Vite
- React Router DOM
- Context API
- CSS / MUI / Bootstrap
- Mocked APIs & Authentication
